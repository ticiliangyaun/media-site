人眼 · 相机 · 校正伽马

对应第 05-1 讲：视杆细胞对暗部极敏感（对数伽马，曲线上弯），相机 CMOS 客观记录（线性伽马）， 两者之差由显示器的校正伽马补齐——伽马值越大，曲线弧度越大，画面越暗。

人眼（对数伽马 · 上弯） 相机 CMOS（线性） 校正伽马 γ

拖动看曲线弧度变化：γ 越大 → 曲线越弯 → 画面越暗。 常见取值 1.8 / 2.0 / 2.2 / 2.4 / 2.6（Rec.709 = 2.4，sRGB = 2.2，DCI-P3 = 2.6）。

三原色加色公式

对应第 05-1 讲：红 + 绿 = 黄，绿 + 蓝 = 青，蓝 + 红 = 品，三色相加 = 白。 拖动三个通道的数值，让三个圆互相重叠——重叠处就是加色结果。

减色公式（把白里的通道减到 0）结果互补关系
白 − 红青红 ↔ 青
白 − 绿品绿 ↔ 品
白 − 蓝黄蓝 ↔ 黄

色环上穿过中心画 180° 的线，对面那个颜色就是它的互补色——课程里纠色的第一反应： 画面偏青就加红，偏黄就加蓝。

CIE 1931 马蹄图与常见色彩空间

对应第 05-1 / 05-2 讲：色彩空间（色域）就是在马蹄图上画一个三角形， 由基准色度（色相 + 饱和度）、伽马、白点三个数值共同确定。 勾选下面的色彩空间看它的三角形与白点位置。

色彩空间伽马白点用途
Rec.7092.4D65最通用，高清电视标准
sRGB2.2D65互联网与打印机
Rec.20202.4D65HDR，范围最大
DCI-P32.6D63影院放映（环境全黑，故 γ 大）
Display P32.2D65苹果，色度同 P3

色温：越高越蓝越冷（D65 = 6504K，人眼最舒服），越低越黄红越暖。 项目设置（第 05-2 讲）：Windows = Rec.709 / Gamma 2.4，Mac = Rec.709-A。

一级校色轮：四个旋钮的作用域

对应第 05-4 讲。横轴 = 原画面亮度（0 黑 → 1023 白），纵轴 = 调整后的亮度。 勾选看每条曲线各自的"手伸多长"——偏移整体动、暗部动 0 端、亮部动 1023 端， 中灰两端都不动但实际作用区间偏下（因为人眼对暗部敏感）。

偏移 Offset整体无

补偿性原则：压暗部 → 提亮部（暗部被一起抬起）→ 必须压中灰把暗部压回去。提高谁，就压低谁。

HDR 色轮：六档分区

HDR 色轮把画面切成六档，建议从大范围逐级收到小范围： Shadow / Light → Dark / Highlight → Black / Specular。

暗部三档 Black / Dark / Shadow 亮部三档 Light / Highlight / Specular

对比度与轴心 · 肩部趾部

对应第 05-7 讲。对比度以轴心为分界线向两端拉伸——中间调舒张变清晰是优点， 亮部暗部像素向肩部（上 5%）与趾部（下 5%）堆积是缺点。

灰渐变经对比度处理后（注意两端堆积）
波形：亮部与暗部被压成实线 = 细节被盖住
一级校色轮的对比度会带高饱和度，需要反向补偿； HDR 色轮里的对比度几乎不影响饱和度——这是两者最大的区别。
